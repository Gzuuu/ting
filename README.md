# 📄 TING (Trybe Is Not Google)  

## 📋 Descrição Breve  
Este projeto simula um algoritmo de indexação de documentos semelhante ao utilizado pelo Google. Desenvolvido durante meus estudos de Ciência da Computação com Python, o programa é capaz de identificar ocorrências de termos em arquivos TXT e manipular diferentes estruturas de dados.  

## 🛠️ Como Rodar o Projeto  
1. Clone o repositório:  
   ```bash  
   git clone https://github.com/Gzuuu/ting.git  
   ```  
2. Entre na pasta do projeto:  
   ```bash  
   cd ting  
   ```  
3. Instale as dependências:  
   ```bash  
   python3 -m pip install -r dev-requirements.txt  
   ```  
4. Para executar os testes:  
   ```bash  
   python3 -m pytest  
   ```  

## 💻 Tecnologias Utilizadas  
- **📝 Linguagem**: Python  
- **🔍 Bibliotecas**: Pytest  

## ⚙️ Funcionalidades  
- 🔎 Simulação de um **algoritmo de indexação de documentos** capaz de identificar ocorrências de termos em arquivos TXT.  
- 🔧 Manipulação de **pilhas**, **deques**, **nós**, **listas ligadas** e **listas duplamente ligadas**.  

## 🌟 Principais Aprendizados  
- 🤖 Desenvolvimento de algoritmos para processamento e busca de dados.  
- 🏗️ Manipulação de estruturas de dados complexas.  
- ✅ Escrita de testes utilizando **Pytest**.
